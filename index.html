R methods library · microbiome analysis

Check the stability of a microbiome result before interpreting it.

A reusable workflow for measuring how filtering, zero handling, inference, covariate adjustment and longitudinal modelling affect microbiome results.

feature table→ input gate→ compositional sensitivity→ inference + adjustment→ longitudinal diagnostics→ follow-up analysis

What the toolkit separates

Data typeGenuine counts and relative abundance follow different analysis paths.
PreprocessingPrevalence and zero handling are evaluated across explicit specifications.
InferenceCLR tests are grouped as checks of inferential sensitivity on a common representation.
TimeWindowed population contrasts and subject-level mixed models remain separate estimands.

Public case study

The included Baby Biome Study example uses public relative-abundance profiles to demonstrate the diagnostic workflow.

554infants in the primary day-0–7 comparison
64features evaluated across the preprocessing sensitivity grid
61 / 61feature-level mixed models converged and were non-singular
50 / 61windowed and mixed-model directions agreed around day 210, illustrating estimand sensitivity
Direction, effect magnitude, feature estimability and rank are reported separately because they can show different stability patterns.

Use it as an analysis gate

Run the robustness layer after basic data preparation and before committing to biological mechanisms, prediction models or follow-up validation. It is suitable both for re-analysis of published public datasets and for auditing a new dataset before deeper modelling.
